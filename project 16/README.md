Digital Clock Using Verilog HDL
Overview

This project implements a 24-hour digital clock using Verilog HDL. The clock displays time in the format:

HH : MM : SS


where:

HH represents hours (00–23)

MM represents minutes (00–59)

SS represents seconds (00–59)

The design includes a reset input and is verified using a Verilog testbench.

Features

24-hour time format

Hours range from 00 to 23

Minutes range from 00 to 59

Seconds range from 00 to 59

Synchronous reset

Automatic rollover from 23:59:59 to 00:00:00

Fully synthesizable RTL

Testbench for functional verification

Simulation waveform support

Working Principle

The digital clock uses a clock signal to increment the time.

The counting sequence is:

00:00:00
00:00:01
00:00:02
     .
     .
00:00:59
00:01:00
     .
     .
00:59:59
01:00:00
     .
     .
23:59:59
00:00:00


When the seconds counter reaches 59, it resets to 00 and the minutes counter increments.

When the minutes counter reaches 59, it resets to 00 and the hours counter increments.

When the hours counter reaches 23 and the time is 23:59:59, all counters return to zero.

Simulation

The testbench generates a clock and applies reset before allowing the digital clock to count.

For demonstration purposes, the RTL uses a configurable clock divider. The parameter CLK_FREQ represents the input clock frequency.

For example:

parameter CLK_FREQ = 10;


can be used during simulation so that a clock tick occurs quickly.

Using Icarus Verilog

Compile the design and testbench:

iverilog -o digital_clock_sim src/digital_clock.v tb/digital_clock_tb.v


Run the simulation:

vvp digital_clock_sim


The testbench generates a VCD waveform file:

digital_clock.vcd


Open it using GTKWave:

gtkwave digital_clock.vcd

00:00:59 -> 00:01:00
00:59:59 -> 01:00:00
23:59:59 -> 00:00:00

Reset operation

Seconds counting

Minutes-to-hours rollover

24-hour rollover

Normal continuous counting
